In recent times, computation has become increasingly decentralized. Data is transferred to and operated on across multiple devices in order to provide services, and this class of problems can be broadly classified as Multiparty computation (MPC).
A very common example is deferring some computation to a cloud server which is more powerful and has elastic computation capabilities. 
However, since it is owned and operated by another party, a remote server may not automatically provide the same security and privacy guarantees as the user's own machine. Besides user requirements, cybersecurity regulations also require methods to secure data from such parties, such as in the case of private healthcare data, or other personal information (cite\_gdpr).

Often attributed to Andrew Yao's seminal work in 1986 \cite{FOCS:Yao86}, a Garbled Circuit (GC) is a cryptographic building block that can be used to build such PSI protocols. Garbled Circuits allow any function that can be expressed as a boolean circuit to be converted into a two-party protocol (this also requires an Oblivious Transfer protocol, which we discuss later) where the function takes inputs from both parties but does not reveal anything besides the final output of the function.  
For about more than a decade after this work, Garbled Circuits were considered to not be practical, due to bandwidth and computation inefficiencies. However, there has been ongoing work in the field that has led to optimizations that allow them to be somewhat usable in niche applications such as blockchains and even for generic 2PC in systems like Fairplay \color{red}{cite Fairplay}. 

In this work, we aim to convert the proof of one such optimization (Free XOR) to a State-separating proof (SSP) format, and formally verify the correctness of this converted proof. Formal verification allows us to base the correctness of some protocol or scheme on mathematical and logical constructs, rather than exhaustively testing edge cases, as is often the case in software engineering. We use Domino, a proof verification tool for SSPs, which is currently under development, and examine the suitability of its current feature set for complex proofs, while also attempting to validate the above proof. \color{red}{rewrite}

The initial goal of this project was to verify the Half-Gates garbling scheme. However, since the Half-Gates scheme works under the FreeXOR assumption, we realised that this would require us to first solve the same problem for the FreeXOR scheme. Due to the limited timeframe of the project, we were unable to do both, and leave Half-Gates as future work, which we describe in more detail later.

The rest of this paper is organized as follows: Section 2 contains background information on Garbling schemes, optimizations, and Domino. Section 5 contains concluding remarks and future work.
