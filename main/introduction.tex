Multiparty computation is a common scenario in the present time, where data is transferred and operated on across multiple devices in order to provide services. A very obvious example is deferring some computation to a cloud server which has higher and more elastic computation capabilities. However, there also exist regulations as well as requirements that may bring the need to secure such data from third parties, such as in the case of healthcare, or personal information (cite\_gdpr).
