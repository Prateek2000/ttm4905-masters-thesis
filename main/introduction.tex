Multiparty computation (MPC) is a common scenario in the present time, where data is transferred and operated on across multiple devices in order to provide services. A very obvious example is deferring some computation to a cloud server which has higher and more elastic computation capabilities. As a consequence, there also exist regulations as well as requirements that bring the need to secure such data from third parties, such as in the case of healthcare, or personal information (cite\_gdpr). 
Two-party computation (2PC) is a subset of MPC in which two parties want to evaluate a function that takes inputs from both parties, but with the constraint that they do not wish to reveal the inputs to each other. Examples could be matching if a user's password is in a leak database, or jointly computed biometric validation, which are actually examples of a more well defined problem called Private Set Intersection (PSI) \cite{USENIX:PinSchZoh14}.
